OneGate logo assets
===================

Brand color: indigo #4f46e5 (lighter accent #6366f1, deep #4338ca, on-dark accent #a5b4fc).
Concept: a gateway portal with the brand node passing through it. One secure gate for every request.

Vector (svg/) — scalable, use these wherever you can:
  onegate-mark.svg          Line mark, indigo. For light backgrounds.
  onegate-mark-white.svg    Line mark, white. For dark backgrounds.
  onegate-badge.svg         Rounded-square app icon, indigo gradient with white mark.
  onegate-lockup.svg        Badge + "OneGate" wordmark, dark text. For light backgrounds.
  onegate-lockup-white.svg  Badge + wordmark, white text. For dark backgrounds.

Raster (png/) — transparent background:
  onegate-badge-16/32/48/64/128/256/512.png   App icon / favicon sizes.
  favicon-32.png                               Ready-to-use favicon.
  onegate-mark-256/512.png                     Indigo line mark.
  onegate-mark-white-256/512.png               White line mark (dark backgrounds).
  onegate-lockup-512.png                       Full lockup, dark text.
  onegate-lockup-white-512.png                 Full lockup, white text.

Notes:
- The SVGs are the source of truth. Regenerate any size from them.
- The wordmark uses a system sans-serif (the OneGate UI font). For print or a fixed
  brand wordmark, outline the text in your design tool.
- Clear space: keep at least the height of the badge's corner radius around the lockup.
